THE TECHNOLOGY, WITHOUT THE MYSTERY

What is an API?
The connection behind the screen.

API stands for Application Programming Interface: a defined way for software to ask other software for information or an action. You do not need to write code to use Driver Tide.

  1. 01 / FRONT END

    What people see

    The branded pages your team and clients use in a browser: a portal, a form, a shared view of the work.

  2. 02 / BACK-END API

    Where the rules run

    The front end asks the server to assign an eligible driver or record a delivery update. The back end checks identity, permissions and business rules.

  3. 03 / DATABASE

    What the system remembers

    Approved changes are saved. The API returns a result, and the front end shows the updated information.

What you are buying

A managed API service with a branded browser front end for the workflows we agree on. Clients use the front end without needing an API key. External developer access and custom integrations are agreed separately.

OUR CODING STACK

The tools behind Driver Tide

A stack is the group of technologies that deliver a service.

C# + ASP.NET Core + .NET 10
C# is the language. .NET runs the code, and ASP.NET Core supplies the web server and API framework. Take the free C#/.NET course ↗
Blazor + HTML + CSS + JavaScript

PostgreSQL + Supabase

DigitalOcean + Cloudflare + Stripe
DigitalOcean hosts the running service; Cloudflare manages domain routing. Tide Casa uses Stripe for eligible software builds and maintenance. Business-customer payments require their own integration.

A SMALL TECH DICTIONARY

Words you will hear

Endpoint
A particular API address used for an operation. This service’s managed front end uses its back-end endpoints.
Request, response & JSON
A request asks; a response answers. JSON is a structured text format often used to carry the information.
Authentication & authorization
Authentication checks who you are. Authorization checks which records and actions you can access.
Hosting, deployment & integration
Hosting keeps the service running. Deployment publishes a reviewed version. An integration connects another service to an agreed workflow.
Webhook
A notification one service sends to another. Stripe sends verified billing notifications to Tide Casa.

BEFORE YOU GET STARTED

Clear answers.

Does $199 include drivers or delivery charges?

No. This is software hosting and maintenance. Driver pay, transport and processing costs are separate.

Are driver payouts live?

Driver-payment workflows have separate provider readiness and activation requirements. Buying this software package does not activate payouts. Approved shared-network delivery payments carry the disclosed 5% platform fee when that feature is enabled; own-driver payments have no network fee.

Can this promise an arrival time?

No. Dispatch rules consider availability, coverage and capacity. They do not estimate travel times, optimize routes or guarantee arrival.

Where do drivers and customers enter?

Drivers use the existing BarTide driver sign-in. Restaurant customers use order.tide.casa. Private workspaces still require authorized accounts.

What happens after I pay?

Tide Casa confirms payment through Stripe, then guides you to create your service account and provide your build details. We review your needs with you. Existing portal access is managed separately; a payment return page alone does not grant access to private records.

Do I need an account to take the courses?

No. Open a language path and start exploring. Lessons and exercises are free to access without signing in.
