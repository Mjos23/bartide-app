THE TECHNOLOGY, WITHOUT THE MYSTERY

What is an API?
The connection behind the screen.

API stands for Application Programming Interface: a defined way for software to ask other software for information or an action. You do not need to write code to use Collect.

  1. 01 / FRONT END

    What people see

    The branded pages your team and clients use in a browser: a portal, a form, a shared view of the work.

  2. 02 / BACK-END API

    Where the rules run

    The front end asks the server to load a permitted fictional account or record a preview proposal. The back end checks identity, permissions and business rules.

  3. 03 / DATABASE

    What the system remembers

    Approved changes are saved. The API returns a result, and the front end shows the updated information.

What you are buying

A managed API service with a branded browser front end for the workflows we agree on. Clients use the front end without needing an API key. External developer access and custom integrations are agreed separately.

OUR CODING STACK

The tools behind Collect

A stack is the group of technologies that deliver a service.

C# + ASP.NET Core + .NET 10
C# is the language. .NET runs the code, and ASP.NET Core supplies the web server and API framework. Take the free C#/.NET course ↗
Blazor + HTML + CSS + JavaScript
Blazor builds interactive front ends with C#. HTML supplies structure, CSS controls appearance, and JavaScript handles browser features. Learn JavaScript and web foundations ↗
PostgreSQL + Supabase
The shared Tide back end stores structured records in PostgreSQL and uses Supabase for hosted data and account sign-in. Private workspaces enforce authorization on the server.
DigitalOcean + Cloudflare + Stripe
DigitalOcean hosts the running service; Cloudflare manages domain routing. Collect’s software checkout awaits provider approval. Simulated preview payments do not connect to Stripe or move money.

A SMALL TECH DICTIONARY

Words you will hear

Endpoint
A particular API address used for an operation. This service’s managed front end uses its back-end endpoints.
Request, response & JSON
A request asks; a response answers. JSON is a structured text format often used to carry the information.
Authentication & authorization
Authentication checks who you are. Authorization checks which records and actions you can access.
Hosting, deployment & integration
Hosting keeps the service running. Deployment publishes a reviewed version. An integration connects another service to an agreed workflow.
Webhook
A notification one service sends to another. Stripe sends verified billing notifications to Tide Casa.
